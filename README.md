# روضتي (Rawdati) - مشروع تجريبي لاستعراض دور الحضانة

مشروع محفظة أعمال (Portfolio Demo) يقدّم واجهة نموذجية لاستكشاف ومقارنة دور الحضانة ورياض الأطفال، مع استعراض المرافق والخدمات، وتجربة حجز جولات تعريفية ونظام تقييمات، إلى جانب لوحة تحكم إدارية تفاعلية بوضع تجريبي.

> **تنويه**: هذا المشروع عبارة عن نموذج عمل تجريبي (Portfolio Project) لأغراض العرض البرمجي، وجميع البيانات والحضانات والتقييمات المعروضة فيه هي بيانات محاكاة افتراضية غير حقيقية.

## 💡 نظرة عامة وفكرة المشروع

يهدف مشروع **«روضتي»** إلى تقديم واجهة مستخدم متكاملة وحديثة لاستعراض دور الحضانة، من خلال:
- **أولياء الأمور**: البحث المفلتر حسب المدينة والحي والميزانية، واستعراض المرافق، وحجز الجولات التجريبية، وحفظ الحضانات في المفضلة.
- **أصحاب الحضانات**: تقديم طلبات إضافة حضانة جديدة وتحديث تفاصيل المركز للمراجعة.
- **إدارة المنصة**: لوحة تحكم في وضع تجريبي تتيح معاينة الطلبات، إدارة الحضانات المنشورة، ومراجعة التقييمات.

---

## 🔄 تجربة المستخدم ومسار العمل

1. **بوابة الدخول والترحيب (`WelcomeAuthGate.tsx`)**:
   - تظهر للزائر الجديد وتتيح إنشاء حساب (بدور ولي أمر افتراضياً)، أو تسجيل الدخول، أو المتابعة الفورية كزائر لتصفح الحضانات.
2. **استكشاف الدليل والمقارنة**:
   - البحث بالاسم والمدينة، وتطبيق فلاتر الأسعار والمناهج (منتسوري، لغات، رعاية الرضّع، كاميرات المراقبة).
3. **التفاعل وطلب الجولات**:
   - إمكانية حفظ الحضانات في المفضلة، أو تقديم طلب حجز جولة تعريفية أو استشارة (تنبيه تجريبي).

## 🖥️ دليل الواجهات والشاشات

- **بوابة الترحيب والتسجيل (`WelcomeAuthGate.tsx`)**: واجهة تسجيل دخول وإنشاء حساب أنيقة للزوار.
- **شريط التنقل العلوي (`Header.tsx`)**: يحوي الشعار، روابط التنقل، مفضلة الزائر، ومبدّل اللغة (العربية / English).
- **محرك البحث الرئيسي (`HeroSearch.tsx`)**: حقول البحث السريع بالمدينة والحي والميزانية والوسوم الشائعة.
- **الفلاتر المتقدمة (`FilterSidebar.tsx` & `MobileFilterDrawer.tsx`)**: تصفية ديناميكية للأسعار، المناهج، أوقات الدوام، والخدمات.
- **بطاقات الحضانات (`NurseryCard.tsx`)**: عرض صورة المركز، التقييم، الرسوم، والخدمات مع أزرار الحجز والمفضلة.
- **الخريطة التفاعلية (`MapView.tsx`)**: استعراض التوزيع الجغرافي للحضانات.
- **تفاصيل الحضانة (`NurseryDetailsModal.tsx`)**: استعراض ألبوم الصور، جدول الأنشطة، والمرافق.
- **نماذج الحجز والتواصل (`BookingTourModal.tsx` & `FreeConsultationModal.tsx`)**: نماذج تجريبية للمعاينة.
- **لوحة تحكم المشرف (`AdminPortalPage.tsx`)**: صفحة الإدارة المستقلة.

## 🛡️ لوحة تحكم المشرف (وضع تجريبي)

لوحة تحكم الأدمن مصممة لتعمل في **«وضع تجريبي - محاكاة محلية»**:
- **عزل بيانات المستخدمين**: لا تقرأ لوحة الأدمن مجموعة المستخدمين الحقيقية في قاعدة البيانات، ولا تعرض أي بريد إلكتروني أو رقم هاتف حقيقي لحماية الخصوصية.
- **شارة واضحة**: تعرض اللوحة شارة تنبيهية بارزة تؤكد أنها في وضع تجريبي للعرض فقط.
- **إدارة محلية آمنة**: عمليات تعديل الأدوار وإدارة الحسابات مقيدة محلياً ولا تسمح بتصعيد الصلاحيات في قاعدة البيانات السحابية.
- **متابعة الطلبات والتقييمات**: معاينة طلبات الانضمام، مراجعة واعتماد التقييمات، وإدارة الحضانات المنشورة في الدليل.

## 🌐 خطوات النشر على Vercel

المشروع مُهيأ للنشر السلس على منصة **Vercel**:

1. ارفع المشروع إلى حسابك على GitHub في مستودع جديد.
2. سجّل الدخول إلى [Vercel](https://vercel.com) واختر **Add New Project**.
3. استورد المستودع من GitHub وحدد الإعدادات التالية:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
4. أضف متغيرات البيئة الخاصة بـ Firebase إن وُجدت من لوحة تحكم Vercel Environment Variables.
5. انقر على **Deploy** وسيتم نشر التطبيق فوراً برابط HTTPS مباشر وسريع.

## 🔒 الأمان والخصوصية

- **قواعد Firestore الصارمة**: قراءة مستندات المستخدمين مقصورة على صاحب المستند نفسه فقط لمنع استعراض حسابات الآخرين.
- **منع تصعيد الصلاحيات**: تقييد صلاحيات إنشاء الحسابات بـ `parent` أو `owner` وتثبيت الدور بحيث لا يمكن للمستخدم تعديله.
- **حماية بيانات الأدمن**: عزل بيانات لوحة الإدارة لتعمل على حسابات تجريبية افتراضية للمعاينة فقط دون كشف بيانات حقيقية.
- **حدود البيانات**: التحقق من حقول المفضلة ووضع حد أعلى للصور المرفوعة في التقييمات.
