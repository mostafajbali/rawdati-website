# روضتي (Rawdati) - دليل الحضانات المعتمد في المملكة العربية السعودية

منصة رقمية حديثة وشاملة تمكّن أولياء الأمور من استكشاف، مقارنة، وحجز جولات تعريفية في أفضل دور الحضانة ورياض الأطفال المعتمدة من وزارة التعليم في المملكة العربية السعودية، مع استعراض صور واقعية للمرافق ومراجعات موثقة من الأهالي.

---

## 💻 اللغات والتقنيات المستخدمة في المشروع (Tech Stack)

### 1. لغات البرمجة والترميز الأساسية:
- **TypeScript (v7.0+)**: اللغة البرمجية الرئيسية لكتابة المنطق البرمجي والمكونات بدقة عالية وأمان كتابي كامل (Strict Type Safety).
- **JavaScript (ESNext)**: البيئة المعيارية لتشغيل الأكواد والـ Bundling الحديث.
- **HTML5 (Semantic)**: هيكلة الصفحات الموجهة لمحركات البحث (SEO)، مع دعم كامل لاتجاه القراءة من اليمين إلى اليسار (`dir="rtl"`) واللغة الإنجليزية (`dir="ltr"`).
- **CSS3 / Modern CSS**: التنسيقات الحديثة، التدرجات اللونية، وتأثيرات الـ Glassmorphism والتنقل الانسيابي.

### 2. مكتبات وأطر العمل (Frameworks & Libraries):
- **React 19**: واجهة المستخدم التفاعلية ومبنية بنظام المكونات المستقلة (Functional Components & Hooks).
- **Vite 8**: أسرع أداة بناء وتطوير حديثة (Bundler & Dev Server).
- **Tailwind CSS (v4)**: إطار التنسيق السريع والمبني على Design Tokens حديثة ومخصصة لمشروع روضتي.
- **Motion**: مكتبة التحريكات والتفاعلات البصرية المتقنة.
- **Lucide React & Google Material Symbols**: أيقونات تفاعلية بنظام التصميم الرسمي المعتمد.

### 3. الخدمات السحابية وقاعدة البيانات (Backend & Cloud):
- **Firebase Firestore**: قاعدة بيانات سحابية لحظية NoSQL لتخزين تقييمات أولياء الأمور ومرفقات صور المرافق.
- **Firebase Authentication**: تسجيل الدخول الآمن بحساب جوجل (Google Sign-In) للتحقق من هوية أولياء الأمور.
- **Google Cloud Platform (GCP)**: استضافة السيرفر والإنتاج السحابي.

## 🌟 مميزات المنصة الرئيسية

1. **شعار روضتي المفرغ اللطيف (SVG)**:
   - أيقونة شمس ونبتة طفولية مرحة بدون خلفيات معتمة، تمنح المنصة طابعاً دافئاً ومريحاً للأمهات والآباء.
2. **محرك بحث وفلاتر ذكية**:
   - البحث بالاسم والمدينة والميزانية الشهرية.
   - فلاتر سريعة: المناهج (منتسوري، ثنائية اللغة)، الأمان (كاميرات بث مباشر 24/7)، الأعمار (تقبل الرضّع)، والدوام المسائي.
3. **عرض شبكي وخريطة تفاعلية (`MapView`)**:
   - إمكانية التبديل بين بطاقات العرض التفاعلية واستكشاف الحضانات على خريطة جغرافية حسب المدن (الرياض، جدة، الشرقية، مكة).
4. **الملف التفصيلي الشامل للحضانة (`NurseryDetailsModal`)**:
   - استعراض الرسوم، الطاقة الاستيعابية، نسبة المعلمات للأطفال، الجدول اليومي، تدابير السلامة، ورابط محادثة واتساب مباشر.
5. **جدار التقييمات وصور المرافق الحقيقية**:
   - مراجعات واقعية من أولياء أمور مسجلين، مع إمكانية إضافة تقييم جديد مع صور المرافق وحفظها في Firestore.
6. **قسم «من نحن / عنا»**:
   - إبراز رسالة المنصة، ركائز الثقة الأربع، وإحصائيات المنصة بالأرقام (+500 حضانة، +15,000 ولي أمر).
7. **نظام استشارات وحجز جولات مجانية**:
   - نماذج تفاعلية لطلب استشارة هاتفية مجانية وحجز موعد زيارة للمركز.
8. **دعم كامل للغتين (العربية / English)**:
   - تبديل فوري عبر زر الناف بار بين العربية والإنجليزية مع تعديل تلقائي للهيكلية واتجاه القراءة (RTL / LTR).
9. **تصميم متجاوب 100%**:
   - متوافق تماماً مع جميع مقاسات الهواتف الذكية والأجهزة اللوحية والحواسيب المكتبية والشاشات العريضة.

## 🚀 تشغيل المشروع محلياً (Local Development)

### المتطلبات:
- تثبيت **Node.js** (الإصدار 18 أو أحدث).
- مدير الحزم **npm** أو **pnpm**.

### خطوات التشغيل:

1. **تثبيت الحزم البرمجية:**
   ```bash
   npm install
   ```

2. **تشغيل خادم التطوير التجريبي:**
   ```bash
   npm run dev
   ```
   افتح المتصفح على: `http://localhost:3000`

3. **فحص الأخطاء والأنواع:**
   ```bash
   npm run lint
   ```

4. **بناء نسخة الإنتاج:**
   ```bash
   npm run build
   ```

5. **معاينة نسخة الإنتاج محلياً:**
   ```bash
   npm run preview
   ```
