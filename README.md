# روضتي (Rawdati) - دليل وحجز الحضانات المعتمد في المملكة العربية السعودية

منصة رقمية وطنية حديثة وشاملة تمكّن أولياء الأمور من استكشاف، مقارنة، وحجز جولات تعريفية واشتراكات في أفضل دور الحضانة ورياض الأطفال المعتمدة من وزارة التعليم في المملكة العربية السعودية، مع استعراض صور واقعية للمرافق ومراجعات موثقة من الأهالي، ولوحة تحكم إدارية متكاملة مدعومة بقاعدة بيانات سحابية لحظية.

## 💡 نظرة عامة وفكرة عمل الموقع (What Rawdati Does)

يعالج موقع **«روضتي»** التحديات التي تواجه أولياء الأمور عند البحث عن بيئة تعليمية ورعائية آمنة لأطفالهم دون سن المدرسة، ويقدم حلاً رقمياً متكاملاً يربط بين:
- **أولياء الأمور**: للبحث المفلتر، معرفة الرسوم بدقة، تفقد تراخيص وزارة التعليم، قراءة تقييمات واقعية، وحجز مواعيد الجولات والاشتراك.
- **أصحاب ومديرات الحضانات**: لتسجيل مراكزهن المعتمدة، استقبال طلبات أولياء الأمور وتحديث بيانات المرافق والرسوم.
- **إدارة المنصة (الأدمن)**: للإشراف على الجودة، مراجعة وتوثيق رخص المراكز، إدارة حسابات المستخدمين، واعتماد تقييمات الأهالي.

## 🔄 مسار وتجربة المستخدم ودورة العمل

1. **بوابة الدخول الأولى (Welcome Gate)**:
   - عند فتح الموقع لأول مرة، يستقبل المستخدم شاشة دخول وترحيب أنيقة تطلب منه إما **إنشاء حساب جديد**، أو **تسجيل الدخول** إذا كان لديه حساب، أو **التصفح كزائر**.
2. **تخزين بيانات المستخدم في قاعدة البيانات (Firestore)**:
   - بمجرد إنشاء الحساب، تُحفظ بيانات ولي الأمر (الاسم، البريد/اسم المستخدم، رقم الجوال، الرتبة) مباشرة في سحابة Firebase Firestore.
3. **التوجيه التلقائي والذكي حسب الصلاحية**:
   - **إذا سجّل الدخول كـ أدمن (Admin)**: يُوجَّه فوراً إلى **بوابة لوحة تحكم الأدمن المستقلة (`AdminPortalPage`)**، ولا تظهر له واجهة الزوار العادية لضمان سرعة إدارة العمليات.
   - **إذا سجّل الدخول كـ مستخدم/ولي أمر (Parent)**: يدخل إلى الصفحة العامة التفاعلية مع تثبيت هويته، ليتمكن من حفظ المفضلة وحجز الجولات والاشتراك وإضافة التقييمات.
   - **الواجهة العامة محمية ونظيفة**: تم إخفاء أي أزرار أو روابط خاصة بلوحة تحكم الأدمن من واجهة الزوار لضمان الخصوصية والاحترافية.
4. **الاشتراك وحجز الجولات**:
   - يستطيع ولي الأمر استعراض الحضانات، وعند الرغبة في الاشتراك أو حجز جولة تعريفية، يطلب النظام منه التأكيد وتسجيل الدخول لحفظ حجز الاشتراك رسمياً في قاعدة البيانات ليظهر فوراً في لوحة تحكم الإدارة.

## 🖥️ الدليل الشامل لجميع واجهات وشاشات الموقع

تتكون المنصة من منظومة واجهات متناسقة ومبنية بأحدث معايير تجربة المستخدم (UI/UX):

### 1. واجهة بوابة الدخول والتسجيل الترحيبية (`WelcomeAuthGate.tsx`)
- تظهر تلقائياً للزوار غير المسجلين كخطوة أولى.
- تحتوي على تبويبين واضحين:
  - **«إنشاء حساب»**: للمستخدمين الجدد، يتضمن حقول (الاسم الكامل، البريد الإلكتروني، رقم الجوال، كلمة المرور).
  - **«تسجيل الدخول»**: للمستخدمين السابقين، مع إمكانية الدخول السريع أو إدخال بيانات الأدمن.
- زر **«إنشاء حساب»** / **«تسجيل الدخول»** المباشر والواضح.
- روابط سريعة للتبديل بين الحالتين (*لديك حساب بالفعل؟ تسجيل الدخول* / *مستخدم جديد؟ إنشاء حساب*).
- خيار **«تصفح كزائر أولاً»** لمن يرغب في استكشاف الدليل العام قبل التسجيل.

### 2. واجهة شريط التنقل العلوي المتجاوب (`Header.tsx`)
- **شعار روضتي المفرغ اللطيف (SVG)**: أيقونة شمس ونبتة طفولية دافئة بدون خلفيات معتمة.
- روابط التصفح السريع: (الرئيسية، استكشف الحضانات، البرامج التعليمية، آراء المجتمع، سجل حضانتك، من نحن).
- مؤشر الحضانات المفضلة التفاعلي مع عداد لحظي.
- زر تبديل اللغة الفوري بين **العربية** و **English** مع دعم كامل لاتجاه الصفحة (`RTL/LTR`).
- بطاقة المستخدم المسجل (عرض الاسم، بادج الرتبة "ولي أمر" أو "أدمن"، وزر تسجيل الخروج).
- زر الدخول وإنشاء الحساب في حال كان الزائر في وضع الضيف.

### 3. واجهة قسم البحث والترحاب الرئيسي (`HeroSearch.tsx`)
- عنوان جذاب ورسالة ترحيبية لأولياء الأمور مع بطاقة ثقة معتمدة من وزارة التعليم.
- محرك بحث متقدم يبحث لحظياً بالاسم أو الحي أو الكلمات المفتاحية.
- منتقي المدينة الجغرافي (الرياض، جدة، الدمام، مكة المكرمة، الخبر، المدينة المنورة، تبوك).
- محدد الميزانية الشهرية بالريال السعودي.
- أوسمة الفلترة السريعة بنقرة واحدة (منهج منتسوري، كاميرات بث مباشر 24/7، رعاية الرضّع، دوام مسائي ممتد).
- زر حجز استشارة توجيهية هاتفية مجانية.

### 4. واجهة الفلاتر الجانبية المتقدمة (`FilterSidebar.tsx` & `MobileFilterDrawer.tsx`)
- شريط فلاتر متكامل للحواسيب ودرج منبثق مخصص للهواتف الذكية.
- فلترة نطاق السعر بشريط تمرير ديناميكي (1000 - 5000+ ر.س).
- فلترة الفئات العمرية: (الرضّع من شهرين، الدارجون 1-3 سنوات، مرحلة ما قبل الروضة 3-5 سنوات).
- فلترة المناهج: (منتسوري، ثنائية اللغة، البريطاني EYFS، المنهج الوطني المعتمد).
- فلترة المرافق والخدمات: (كاميرات مراقبة، طاقم تمريضي مقيم، وجبات صحية عضوية، مسبح تدريبي، حدائق ألعاب مظللة، مواصلات آمنة).
- فلترة أوقات الدوام: (صباحي عادي، دوام مسائي، دوام مرن بالساعة).

### 5. واجهة شبكة بطاقات الحضانات (`NurseryCard.tsx`)
- بطاقات تفاعلية أنيقة تعرض:
  - صورة الغلاف الحقيقية للحضانة مع وسام الاعتماد والتوثيق الرسمي.
  - الاسم والمدينة والحي والمسافة التقريبية.
  - تقييم النجوم وعدد مراجعات أولياء الأمور المعتمدة.
  - أهم 3 مزايا رئيسية (مثلاً: كاميرات 24/7، لغات، ممرضة).
  - الرسوم الشهرية بالريال السعودي.
  - زر إضافة/إزالة من المفضلة بنقرة واحدة.
  - زر استعراض التفاصيل الكاملة وزر حجز الجولة والاشتراك.

### 6. واجهة الخريطة التفاعلية الجغرافية (`MapView.tsx`)
- إمكانية التبديل بين عرض الشبكة وعرض الخريطة التفاعلية.
- نقاط جغرافية واقعية لكل حضانة توضح الموقع، السعر، وصورة مصغرة مع رابط مباشر للتفاصيل.

### 7. واجهة الملف التفصيلي الشامل للحضانة (`NurseryDetailsModal.tsx`)
- نافذة منبثقة غنية تمنح ولي الأمر فكرة وافية عن المركز:
  - معرض صور حقيقية للمرافق والفصول الدراسية وساحات اللعب.
  - رخصة وزارة التعليم وتاريخ التوثيق.
  - الفئات العمرية المستهدفة ونسبة المعلمات للأطفال (مثلاً معلمة لكل 4 أطفال).
  - الجدول اليومي والأنشطة الإثرائية.
  - معايير الأمان وتدابير السلامة المتبعة.
  - جدار تقييمات أولياء الأمور الخاص بالحضانة مع إمكانية إضافة تقييم جديد.
  - زر محادثة واتساب مباشر مع إدارة الحضانة.
  - زر حجز موعد زيارة واشتراك.

### 8. واجهة حجز الجولة والاشتراك المعتمد (`BookingTourModal.tsx`)
- نموذج حجز زيارة أو تسجيل اشتراك.
- تحديد اليوم والفترة المفضلة للزيارة (صباحية / مسائية).
- إدخال اسم الطفل وعمره والملاحظات الخاصة.
- يلزم تسجيل الدخول لربط الاشتراك بحساب ولي الأمر وحفظه فورياً في قاعدة البيانات Firestore لتتمكن إدارة المنصة والحضانة من معالجته.

### 9. واجهة تسجيل حضانة ومركز جديد (`RegisterNurseryModal.tsx`)
- نافذة مخصصة لمالكات ومديرات دور الحضانة.
- إدخال اسم المركز، المدينة، الحي، رقم ترخيص وزارة التعليم الرسمي، السعر المقترح، وبيانات التواصل.
- إرسال الطلب ليذهب مباشرة إلى لوحة تحكم الأدمن في حالة «قيد المراجعة» للتحقق من الرخصة قبل النشر العام.

### 10. واجهة لوحة تحكم الأدمن المستقلة (`AdminPortalPage.tsx`)
بوابة إدارية كاملة لا تظهر للعامة، وتتضمن:
- **شاشة تسجيل دخول الأدمن الخاصة** مع خيار التعبئة السريعة للبيانات الافتراضية.
- **شريط الإحصائيات اللحظي**: إجمالي المستخدمين، الحضانات المعتمدة، طلبات التسجيل المعلقة، المراجعات، الحجوزات، والاستفسارات.
- **تبويب إدارة المستخدمين**: استعراض كافة المسجلين من قاعدة البيانات، رؤية بياناتهم (الاسم، البريد، الجوال، تاريخ التسجيل)، وإمكانية تعديل صلاحياتهم (ولي أمر / مالك حضانة / أدمن).
- **تبويب طلبات تسجيل الحضانات**: فحص التراخيص والبيانات، اعتماد الحضانة لتظهر فوراً في الدليل العام، أو رفضها مع كتابة سبب الرفض.
- **تبويب مراجعة التقييمات**: مراجعة تعليقات الأهالي وصور المرافق المرفوعة واعتمادها أو حجبها.
- **تبويب سجل الحجوزات والاشتراكات**: استعراض اشتراكات وجولات أولياء الأمور والتواصل معهم.
- **تبويب إدارة الحضانات المباشرة**: إضافة حضانة جديدة ببياناتها الكاملة، تعديل حضانة حالية، أو حذفها.

### 11. واجهة طلب الاستشارة التعليمية المجانية (`FreeConsultationModal.tsx`)
- خدمة إرشادية تقدم لأولياء الأمور الجدد لاختيار الحضانة المناسبة بناءً على احتياجات طفلهم وميزانيتهم وموقع سكنهم.

### 12. واجهة البرامج والمناهج التعليمية (`EducationalProgramsModal.tsx`)
- دليل معرفي وتثقيفي يشرح الفروقات بين المناهج العالمية المعتمدة: (المنتسوري Montessori، ريجيو إميليا Reggio Emilia، النظام البريطاني EYFS، والمنهج الوطني الاستقصائي).

### 13. واجهة تجارب المجتمع وآراء الأهالي (`CommunityReviewsModal.tsx`)
- جدار حي يعرض قصص وتجارب واقعية من أمهات وآباء استخدموا منصة روضتي لاختيار حضانات أطفالهم.

### 14. واجهة درج المفضلة السريع (`FavoritesDrawer.tsx`)
- قائمة جانبية سريعة تسمح لولي الأمر بمقارنة الحضانات التي نالت إعجابه والوصول لملفاتها بنقرة زر واحدة.

### 15. واجهة قسم «من نحن» والركائز الأربع (`AboutUsSection.tsx`)
- استعراض رسالة المنصة ورؤيتها المنبثقة من برنامج تنمية القدرات البشرية ضمن رؤية المملكة 2030.
- ركائز الثقة: (الاعتماد الرسمي 100%، الأمان والمراقبة المستمرة، الكوادر الوطنية المؤهلة، وشفافية الأسعار).

### 16. واجهة التذييل ونموذج التواصل السريع (`Footer.tsx` & `NurseryQuickContactForm.tsx`)
- خريطة الموقع، روابط مساعدة، معلومات التواصل الرسمية، ونموذج سريع لاستفسارات دور الحضانة.

## 💻 التقنيات المستخدمة في المشروع (Tech Stack)

- **TypeScript & React 19**: معمارية حديثة تعتمد على المكونات الوظيفية وأمان الأنواع البرمجية الشامل.
- **Vite 8**: بيئة بناء وتطوير سريعة واستجابة فورية.
- **Tailwind CSS v4**: نظام تصميم متطور وتنسيقات عصرية متوافقة مع جميع الشاشات.
- **Firebase Firestore & Authentication**: قاعدة بيانات سحابية لحظية لتخزين المستخدمين، التقييمات، والاشتراكات بشكل مستمر.
- **Lucide React & Material Symbols**: أيقونات عصرية عالية الدقة.
- **i18n Localization**: نظام ترجمة محلي يدعم العربية والإنجليزية بتبديل اتجاه القراءة تلقائياً.

## 🐙 خطوات رفع وتحديث المشروع على جيت هب (GitHub Guide)

   ```bash
   git remote add origin https://github.com/USERNAME/REPO.git
   git branch -M main
   git push -u origin main
   ```
3. لتحديث المستودع مستقبلاً بعد أي تعديل:
   ```bash
   git add .
   git commit -m "تحديث تطبيق روضتي"
   git push
   ```
